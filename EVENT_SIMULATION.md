# Event scenario simulator

The Data Intelligence page supports side-by-side hypothetical scenarios. Inputs are registration count, venue capacity, and assumed check-in rate. The deterministic calculation returns expected attendance, expected no-shows, capacity utilization, low/medium/high planning risk, and a detected/why/action recommendation.

Every result is labeled **SIMULATION — NOT SAVED**. The simulator does not modify an event or operational record, does not certify safety, and does not claim a learned model. It is a planning calculation based on user-supplied assumptions. Scenarios can be compared in the current page session and removed from view.

The earlier event-specific what-if analysis remains available and unchanged.
